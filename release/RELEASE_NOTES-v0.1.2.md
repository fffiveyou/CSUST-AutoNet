# CSUST AutoNet v0.1.2 — 多代理系统代理适配测试版

发布日期：2026-11-15。Pre-release，Windows x64 便携包。

本版包含 v0.1.1 的稳定性修复，并补齐原先标为“待支持”的代理客户端选项。此前使用者反馈 v0.1.1 暂未发现问题；该反馈不代表本次新增客户端已经实机验收。

## 新增与修复

- FlClash、Clash Verge Rev、Mihomo / GUI.for.Clash、GUI.for.SingBox、v2rayN：支持 Windows 手动系统代理/PAC 的临时关闭与原样恢复。
- 支持按客户端识别运行进程、查找常见安装路径及保存手工选择的 EXE；定位不到程序也不阻止系统代理管理。
- 所有适配器复用同一套系统代理快照逻辑，不退出代理软件、不改订阅、不启停内核。
- 关闭代理中途失败时尝试回滚原设置，并在失败后禁止提交认证。
- 打包显式包含全部适配器，便携版自检会实例化每种受支持适配器，检查动态加载是否完整。
- 保留后台任务安全退出、认证会话清理、旧登录页证据失效处理、日志与状态历史内存限制。

## 支持边界

仅管理当前 Windows 用户的系统代理，不管理 TUN／增强模式、VPN、WinHTTP 或客户端自己的自动代理守护。请在客户端中关闭 TUN／增强模式后使用。本软件不自动判断 TUN 开关；关闭系统代理不保证绕过 TUN。客户端持续重写代理时可能触发准备失败，请检查客户端设置。

Clash for Windows 有既有校园网实机通过记录；新增客户端为实现与离线测试通过，仍需要各客户端的实际使用反馈。自动定位只覆盖已知程序名和常见安装位置，重命名/其他发行包可手工选择路径。

## 更新方法

1. 先从旧版点击“退出程序”，不要同时运行两个版本。
2. 解压 ZIP 到固定位置，保留 `_internal`，运行 `CSUSTAutoNet.exe`。
3. 程序沿用当前用户的配置与 Windows 凭据。选择实际使用的代理软件，确认启用“认证完成后恢复 Windows 系统代理原设置”，保存设置。
4. 若启用开机启动，在新版中保存设置以更新 EXE 路径。
5. 遇到问题请提供软件版本、代理客户端版本、系统代理/TUN 开关及脱敏错误信息；不要上传账号密码或 HAR。
