# CSUST AutoNet v0.1.1 便携测试包

构建日期：2026-11-15。尚未发布到 GitHub Releases，等待真实网络验收。

## 修复

- 退出时不再阻塞界面等待线程池；停止新增任务，待后台检测或认证及代理恢复结束后自动退出。
- 检测失败或新检测进行中使旧登录页证据失效，防止使用过期信息提交认证。
- 认证结束后关闭自建 HTTP 会话并清除凭据回调。
- 最近事件最多保留 500 段，状态机不再累计完整运行历史。

## 本地验证

- 原始 69 项测试在独立临时目录正常结束，历史退出挂起未复现；默认临时目录存在 Windows 用户权限问题。
- 修复后 77 项离线测试连续两次完整通过，进程退出码均为 0；最终资源清理调整后 8 项稳定性测试通过。
- 进程级测试覆盖空闲退出、检测中退出、认证中退出、任务异常及退出期间不再调度新任务。
- 10,000 次状态更新后内存历史仍有界。
- ZIP CRC 检查、235 个文件解压哈希比对通过；解压后的 EXE `--help` 与 `--self-test` 均退出 0。
- 使用隔离配置实际启动便携版窗口并关闭，退出 0；未执行网络任务、读取真实账号或修改系统代理。

这些结果不等同于真实校园网、睡眠唤醒或长时间运行验收。该测试包未签名。

## 用户实测

1. 通过“退出程序”退出旧版，解压本 ZIP 到固定位置，保留 `_internal` 文件夹；不要与旧版同时运行。
2. 运行 `CSUSTAutoNet.exe`。沿用原配置；需要自启动时点击“保存设置”将启动项指向新版所在位置。
3. 点击“立即检测”，随即点“退出程序”：窗口应保持响应，后台任务完成后自动退出。
4. 重新打开并确认自动认证已启用，在方便短暂断网时注销校园网，观察自动重连认证与系统代理恢复。
5. 认证过程中请求退出，应等待代理恢复后自动退出，不需要再次点击。
6. 后续验证睡眠唤醒、Windows 重启登录和至少一天后台运行。报告异常时间与已脱敏日志即可，不要公开账号密码或 HAR。
